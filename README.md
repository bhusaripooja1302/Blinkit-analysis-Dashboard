# 🛒 Blinkit _Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Blinkit Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides a detailed analysis of sales performance, outlet characteristics, item types, ratings, and outlet locations. It helps understand overall business performance and identify important sales trends.

---

## 🎯 Project Objective

The main objective of this project is to:

* Analyze overall sales performance
* Track important business KPIs
* Understand sales by outlet type and location
* Analyze different item categories
* Compare outlet sizes and their sales contribution
* Analyze outlet establishment trends
* Understand average customer ratings
* Create an interactive and user-friendly Power BI dashboard

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **DAX** – Measures and calculations
* **Microsoft Excel** – Data source and data preparation

## 📊 Dashboard Features

### 1. Outlet Establishment

Shows sales performance based on the outlet establishment year and helps identify sales trends over time.

### 2. Outlet Size Analysis

Analyzes sales distribution across:

* Small
* Medium
* High

### 3. Outlet Location Analysis

Compares sales performance across different outlet location tiers:

* Tier 1
* Tier 2
* Tier 3

### 4. Item Type Analysis

Displays the number of items across different product categories such as:

* Fruits and Vegetables
* Snack Foods
* Household
* Frozen Foods
* Dairy
* Canned
* Baking Goods
* Health and Hygiene
* Soft Drinks
* Meat
* Breads
* Others
* Seafood

### 5. Fat Content Analysis

Analyzes items based on:

* Low Fat
* Regular

### 6. Outlet Type Analysis

Compares:

* Supermarket Type 1
* Supermarket Type 2
* Supermarket Type 3
* Grocery Store

The analysis includes:

* Total Sales
* Number of Items
* Average Sales
* Average Rating

## 🎛️ Interactive Filters

The dashboard includes filters for:

---

## 💡 Key Insights

Based on the dashboard:

* Total sales are approximately **$1.20M**.
* The dashboard contains **8,523 items**.
* The overall average sales value is approximately **$141**.
* The average rating is approximately **3.9**.
* **Supermarket Type 1** contributes the highest sales among the outlet types.
* **Tier 3** outlets have the highest sales among the location tiers.
* Medium-sized outlets contribute significantly to overall sales.
* Fruits and Vegetables and Snack Foods are among the highest item categories by item count.
